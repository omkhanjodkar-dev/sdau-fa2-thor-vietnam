--- 3.2 Assumptions ---
(a) The records are separate delivery reports from different missions.
    They are treated as independent; in reality one mission can appear in
    several records, so the p-value is slightly optimistic.  This is a
    limitation of the source data, not of the test.

(b) Normality of the log load inside each group
    Day    n= 4196  skewness=-0.788  Shapiro-Wilk (n=2000): W=0.9583  p=< 2.2e-16
    Night  n= 1695  skewness=-0.279  Shapiro-Wilk (n=2000): W=0.9876  p=7.2e-11
    The log loads are much closer to symmetric than the raw loads
    (group skewness above versus +4.55 for the raw variable), but the
    Shapiro-Wilk test still rejects at this sample size, so the
    Mann-Whitney test is added below as a cross-check.

(c) Equal variances
    F test on the logs: F = 0.605  df = 4195,1694  p-value = < 2.2e-16 
    Levene test        : F = 143.083  df1 = 1  df2 = 5889  p-value = < 2.2e-16 
    The variance ratio is small but the test is significant because n is
    large; for this reason Welch's version of the t-test is used, which
    does not assume equal variances.
